# Organ Donation Process Ontology (ODPO)

Welcome to the **Organ Donation Process Ontology (ODPO)** repository.

This site provides quick access to the ontology, its use cases, and the main project documentation.

---

## Repository overview

- **Project documentation**  
  See the main project description and instructions in the [README](README.md).

- **Ontology file**  
  Browse or download the ontology in Turtle format: [ODPO](ODPO.ttl).

- **Use cases**  
  Read the detailed ODPO use cases and SPARQL examples in [ODPO_USE_CASES](ODPO_USE_CASES.md).

---

## How to use this repository

You can clone or download the repository and open the ontology with tools such as **Protégé** for editing and reasoning, or query it with SPARQL endpoints that support OWL ontologies.
